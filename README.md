# NexaChat

Aplicativo de chat em tempo real preparado para GitHub + Render.

## Render
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: deixe vazio

## Teste
Abra a URL do Render em dois celulares. As mensagens enviadas por um devem aparecer no outro.

## Próximas etapas
Cadastro/login, número de telefone, contatos, conversas privadas, PostgreSQL e autenticação.
